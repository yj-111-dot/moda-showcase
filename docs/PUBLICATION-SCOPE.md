# 公开范围与私有边界

## 本仓库包含

- 面向公众的项目说明和操作流程。
- 本地演示范围与当前限制的摘要。
- 单独编写的静态展示页面及原创 SVG 示意图。
- 公开内容的权利与素材说明。

## 本仓库不包含

- 服装编辑器、几何处理、缝合及仿真的产品实现。
- 智能体执行实现、提示词、内部工具协议及服务端代码。
- 私有知识库、检索资料、可编辑服装源文件及制版规则库。
- 人物模型、碰撞数据、面料原图、纹样源文件及第三方付费素材。
- 模型凭据、配置、客户项目、对话、日志、数据库或测试录制数据。
- 产品安装包、编译产物、源映射、内部研究文档和完整开发历史。

## 仓库之间的关系

公开仓库拥有独立历史，不是完整研发仓库的 fork 或镜像，不从其分支自动同步。展示页只提供说明性浏览，不连接产品服务、调用模型或读取本地设计文件。

后续更新也应只加入明确选定、逐项审阅过的文件。不要将内部项目目录整包复制到这里，再依赖删除文件或忽略规则弥补；已经公开的历史和他人的副本不能靠后续删除收回。

这个仓库展示项目内容与阶段性成果。完整开发过程和权属核验资料由维护方另行保留，公开提交本身不替代独立的原创性或权属审查。
