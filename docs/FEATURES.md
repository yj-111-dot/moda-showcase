# 功能与操作逻辑

本文介绍产品层面的使用方式，不公开内部算法、工具协议或工程实现。

## 专业设计工作区

| 区域 | 面向设计师的作用 |
| --- | --- |
| 三维试衣区域 | 查看服装上身结果，从不同方向观察设计与局部问题。 |
| 二维版片区域 | 查看和编辑版片、线条与缝合关系。 |
| 对象与属性区域 | 选择当前对象，调整相关参数。 |
| 右侧 AI 对话 | 描述设计要求、查看执行反馈、继续修改。 |
| 底部资产区域 | 浏览人物、服装、制版模板、面料、纹样、工艺和扣件。 |

这些区域服务于同一设计项目。公开展示页中的图形只是结构说明，不是产品界面的可运行副本。

## 一次设计如何进行

### 1. 建立项目与选择人物

先确定设计对象与试衣人物，再创建或选用可继续编辑的服装。人物变化可能需要重新安放或试衣，不能把另一人物的合体结果直接当作已验收结果。

### 2. 编辑版片并观察上身效果

设计师可以直接操作，也可以让 AI 在授权范围内完成具体修改。二维结构与三维显示共同用于判断结果；画面能显示不等于物理质量合格。

### 3. 应用面料与局部图案

面料外观与局部贴花是不同的设计对象。已有素材可以用于整件配色或局部图案设计。使用素材仍需遵守各自的许可和权利边界。

### 4. 核对、保存与继续设计

修改后核对目标是否达到、其他保留项是否改变，再保存。需要返工时继续修改或撤回。保存成功与成衣合体质量分别判断。

## 人与 AI 的关系

- 设计师提出目标，也可以随时直接编辑。
- AI 在授权范围内执行任务，明确的设计锁和保留要求仍有效。
- 操作反馈、工作副本与保存结果需要可辨认。
- 停止、接管和撤回属于设计过程的一部分。

这些是产品的工作原则。具体演示覆盖范围见 [DEMO.md](DEMO.md)，不将原则说明当作所有场景均已验收的证明。
